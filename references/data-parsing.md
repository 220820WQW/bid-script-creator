# 数据解析与最终字段约束

本文件约束目标分析、辅助逆向、`get_list` 和 `get_content` 中的 HTML/JSON 解析，以及最终返回字段。必须依据真实响应选择解析方式，禁止套用案例中的选择器、字段路径或数据类型。

## HTML 数据解析

HTML 数据包括页面直接返回的完整 HTML，以及接口 JSON 字段中返回的 HTML 片段。

1. 优先使用 `BeautifulSoup(..., "html.parser")` 解析完整 HTML 结构。
2. 优选使用 CSS 选择器定位元素，如果无法准确定位时才允许使用其他方法进行查找定位元素，例如：`find`。
3. 元素属性使用 `get()`，元素文本使用 `get_text(strip=True)`。
4. 只有提取已定位的 `script`、JavaScript 调用参数或其他非 HTML 局部字符串，且 BeautifulSoup 无法完成时，才允许对局部内容使用 `re`。
5. 所有选择器必须来自目标页面真实 DOM，禁止直接套用案例选择器。

## JSON 数据解析

1. 接口响应为 JSON 时使用 `resp.json()` 转换为字典或列表；无必要时禁止先读取 `resp.text` 再调用 `json.loads()`。
2. 根据真实响应确认顶层及各层数据类型，不得假设顶层一定是字典。
3. 分别确认列表、正文、标题、发布时间和附件的真实字段路径，例如 `data.list`、`data.records` 或 `rows`；示例字段不能作为默认值。
4. 字典字段优先使用 `get()`；列表按已确认的遍历关系或索引读取；多层字段按真实嵌套逐层获取。
5. 字段缺失时返回 `None`、跳过或交由 `get_content` 补齐，必须遵守对应方法契约。

## JSON 与 HTML 混合响应

1. JSON 字段中保存 HTML 时，先用 `resp.json()` 读取真实字段，再把该字段交给 BeautifulSoup 解析。
3. 同一响应中结构化字段和 HTML 片段并存时，各部分分别使用适合的解析方式；标题、时间、正文来源以真实字段位置为准。
4. 页面 HTML 中包含已经确认的 JSON 数据块时，先用 BeautifulSoup 定位局部脚本或元素，再按实际编码方式提取并转换该数据，不得对整页 HTML 使用正则猜测。

## 最终字段约束

无论字段由 `get_list` 提取、由 `get_content` 补齐，还是返回前重新构造，都必须遵守本节。

### title

1. 最终 `title` 首尾不能有空格，且不得包含 `\r`、`\t`、`\n`；出现时优先使用 `handle_str.replace_escape(title)` 处理。
2. 禁止无脑使用 `handle_str.replace_escape(title)`，仅在需要时使用。
3. 标题和发布时间位于同一元素时必须分别提取，最终只保留纯标题。
4. 发布时间位于标题元素的独立子元素中，例如 `<a>标题<span>发布时间</span></a>`，先提取发布时间完整原文，再从标题中排除该子元素全部文本；禁止直接把整个 `a` 的 `get_text(strip=True)` 结果作为标题。
5. 标题与发布时间直接混排，例如 `<a>标题 发布时间</a>`，依据已确认的完整发布时间原文、稳定格式或固定分隔关系拆分。
6. 从标题中去除页面展示的完整发布时间段，包括与日期同时出现的“发布时间”、栏目、来源等附带文本；不得只去除纯日期并留下无关文字。
7. 禁止仅因标题含数字、短横线或疑似日期片段就盲目删除；拆分依据必须来自真实稳定结构。
8. 最终 `title` 必须完整。列表标题末尾出现 `...`、`…`、`……` 等省略标记，并经详情页抽样或稳定页面结构确认属于长度截断时，不得把该截断文本作为最终标题，必须交由 `get_content` 提取详情页完整标题。
9. 标题中间正常使用省略号，或尾部省略号本身属于文章真实标题时，不得误判；是否截断必须来自目标站点的真实验证。

### pubTime

1. 最终 `pubTime` 必须包含完整年月日。
2. 允许直接返回三类纯日期格式：`YYYY-M-D`、`YYYY年M月D日`、`YYYY.M.D`，其中月、日允许一位或两位数字。
3. 允许返回不含额外字符的 `YYYY-MM-DD HH:MM` 或 `YYYY-MM-DD HH:MM:SS`。
4. 页面或接口已经提供干净的日期时间字符串时原样提取，不刻意删除或构造时、分、秒。
5. 发布时间包含“发布时间”、栏目、来源等额外字符时，使用 `extract_and_validate_dates()` 提取纯日期。
6. JSON 返回时间戳时按 `handle_str.time_stamp()` 的实际结果转换并保留日期时间，不得强制截断为纯日期。
